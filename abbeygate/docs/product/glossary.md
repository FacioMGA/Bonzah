# Domain and platform glossary

Insurance-specific and platform-specific terms used throughout this
codebase, documentation, and communications with Lloyd's and partners.

When adding to this glossary: use the exact term as it appears in code
or communications, add the Abbeygate-specific meaning, and flag if the
term has different meanings in other insurance contexts.

---

## Insurance terms

| Term | Definition |
|---|---|
| **MGA** | Managing General Agent. A firm with binding authority from an insurer or Lloyd's syndicate to underwrite policies on their behalf. Abbeygate operates as an MGA. |
| **Coverholder** | Entity with Lloyd's-approved binding authority. Abbeygate holds coverholder PIN `115933OFE` under the Lloyd's binder `B6081 ABBEYGATE0125`. |
| **Binder** | The contractual agreement between an insurer / Lloyd's syndicate and a coverholder granting specific binding authority. In this system: `Binder` is a Prisma model with fields including `umr`, `agreementNumber`, `lloydsReportingVer`. |
| **UMR** | Unique Market Reference. Lloyd's-specific identifier for a risk or binder (e.g. `B6081 ABBEYGATE0125`). |
| **Syndicate** | A group of insurers at Lloyd's that jointly underwrite risks. Reported to via bordereaux. |
| **YOA** | Year of Account. The Lloyd's accounting year in which a risk is written. |
| **Bordereaux / BDX** | Periodic summary reports submitted to the Lloyd's syndicate detailing all risks written, premiums, and claims under a binder. Generated by `XLSX.GENERATE_BORDEREAUX_V52`. |
| **CRS** | Crystal Reports Standard (Lloyd's). Formal reporting specification for bordereaux. Current version: **CRS V5.2**. |
| **NCD / NCB** | No Claims Discount / No Claims Bonus. A premium discount for drivers with no claims history. |
| **Inception date** | The date when policy coverage begins. |
| **Expiry date** | The date when policy coverage ends (typically inception + 1 year). |
| **Renewal** | Continuing a policy for another term after expiry. `RENEWAL.EMAIL_SCAN` identifies policies expiring within 30 days. |
| **Endorsement / MTA** | Mid-Term Adjustment. A formal change to an in-force policy. Recorded as `RiskTransaction` of type `ENDORSEMENT`. |
| **FNOL** | First Notice of Loss. The initial report of a claim event. Creates a `Claim` with status `OPEN`. |
| **Reserve** | Estimated amount set aside to pay a claim. Set via `SET_RESERVE` command. |
| **Pro-rata** | Premium or refund calculated proportionally to the period of coverage. See `backend/modules/pricing/domain/proration.ts`. |
| **Excess** | The amount the policyholder pays before insurance applies (deductible). Field `requiredExcess` in `quoteData`. |
| **Third Party** | A party other than the insurer and the policyholder involved in a claim. |
| **Comprehensive** | Motor insurance covering the policyholder's own vehicle and third-party liability. Value for `coverRequired`. |
| **TPFT** | Third Party Fire and Theft. Covers liability and fire / theft, not own-vehicle damage. |
| **Green Card** | International Motor Insurance Certificate. Generated as part of the issued policy pack. |
| **IPID** | Insurance Product Information Document. A standardised pre-sale document. Generated by the document pack worker. |
| **STP** | Straight-Through Processing. A quote that passes all UW checks automatically (Green Lane). |
| **UW Referral** | A quote that triggers an underwriting referral (Yellow Lane). Requires manual review. |
| **Decline** | A quote rejected by underwriting rules (Red Lane). Cannot be bound. |
| **RLS** | Row-Level Security. PostgreSQL feature enforcing tenant isolation at the database layer. See [SD-004](../architecture/contracts/security.md#sd-004-tenant-isolation-via-postgresql-rls). |
| **PITR** | Point-in-Time Recovery. Restore PostgreSQL to any point in its backup window. See [docs/operate/backup-and-restore.md](../operate/backup-and-restore.md). |

## Platform terms

| Term | Definition |
|---|---|
| **CHAMPS** | The architectural framework: **C**lear Ownership · **H**onest Layers · **A**rchitecture as Code · **M**odular Domains · **P**roduct Contracts · **S**urfaces and Shared Simplicity. See [contracts/modules-and-layers.md](../architecture/contracts/modules-and-layers.md). |
| **Module** | A backend business capability under `backend/modules/`. Has `http/`, `app/`, `domain/`, `infra/` and exposes its public API through `index.ts`. |
| **Product** | A frontend feature unit under `frontend/src/products/`. Exposes `index.ts` as its public API. |
| **Surface** | A frontend route shell under `frontend/src/surfaces/` (`bo`, `client`, `public`). Composes products into pages and handles routing. |
| **RiskTransaction** | The post-bind change-management primitive. Every material change to an issued policy is a `RiskTransaction` row with `transactionType`, `status`, `snapshotDraft`, `snapshotFinal`. |
| **MBE** | Magic B Endorsements. A structured mutation-generator engine in `backend/modules/mbe/`. Produces change sets applied through `RiskTransaction`. **Not** a versioning primitive. |
| **MagicB** | Configurable rules execution layer (compliance, binder, warning, referral, audit). **Not** the product validation authority. |
| **PolicyStateCurrent** | The mutable workspace buffer for all policy lifecycle stages. For issued policies the source of truth is the latest `BOUND RiskTransaction.snapshotFinal`. |
| **PolicyQuoteHistory** | Pre-bind version snapshots. Archives `quoteData` and `quoteResponse` before the workspace is overwritten. Never used post-bind. |
| **PolicySearchIndex** | Denormalised projection table for fast list and search queries. Updated by `POLICY.INDEX_UPDATE` on every policy mutation. |
| **Outbox** | The transactional event relay pattern. Domain events are enqueued to BullMQ only after the Prisma write succeeds. See [contracts/events-and-projections.md](../architecture/contracts/events-and-projections.md). |
| **DLQ** | Dead Letter Queue. In this system, exhausted jobs are logged at `error` level and treated as logical DLQ entries (no physical DLQ queue; ops-level replay is manual). |
| **Green Lane** | Auto-quoted, auto-approved policy flow. UW automation returns `outcome: 'accept'`. Status `QUOTED`. No referral. |
| **Yellow Lane** | Referred quote requiring underwriter review. Outcome `referral`. Status `REFERRAL`. |
| **Red Lane** | Declined quote. Outcome `decline`. Status `DECLINED`. Cannot be bound. |
| **LIGHT projection** | Minimal DB select for hot-path reads (lock state, payment state, status metadata). Defined in `backend/modules/quotes/app/publicAutoQuote/publicSession.ts`. |
| **FULL projection** | Complete DB select including all JSON fields (`quoteData`, `quoteResponse`, `vehicleInfo`, `driverInfo`). |
| **Ratchet** | A CI mechanism where a violation count can only decrease. New violations fail CI; existing ones live in a baseline file. |
| **Composition root** | The single place where dependencies are wired. Backend: `apps/api/router.ts` → `backend/http/composition.ts`. |
| **CardCorp / OPPWA** | The payment gateway used for card payment capture. Integrations in `backend/modules/payments/`. |
| **Creditsafe** | The compliance data provider used for sanctions screening. In `backend/modules/compliance/`. |
| **Puppeteer** | The headless Chromium library used for HTML → PDF document generation. Used by `DOC.*` workers. Cached in `puppeteer-cache/`. |
| **BullMQ** | The Redis-backed job queue library used for all background jobs. Handlers in `backend/workers/handlers/`. |
